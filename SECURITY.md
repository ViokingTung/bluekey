# Security Policy

## Supported Versions

Please ensure you are using the latest version of BlueKey. Security updates are only provided for the latest major release.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within BlueKey, please DO NOT open a public issue. Instead, please send an email to the repository owner or use GitHub's **"Security -> Advisories -> Report a vulnerability"** feature.

All security vulnerabilities will be promptly addressed.
